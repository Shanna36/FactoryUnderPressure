# Factory Under Pressure  
## An OT Cybersecurity Branching Scenario

Factory Under Pressure is an interactive Operational Technology (OT) cybersecurity simulation designed for manufacturing leaders, engineers, operations teams, educators and workshop facilitators.

Built in Twine using the SugarCube story format, the scenario places participants inside a live cyber incident affecting a connected smart factory. Players must balance production, safety, resilience, communications and business continuity as the situation escalates.

The experience is designed to encourage discussion around real-world OT cyber challenges rather than test technical expertise.

---

## Scenario Overview

Participants take part as the leadership team of a fictional advanced manufacturing company supplying aerospace and medical sectors.

As suspicious activity develops into a full cyber incident, players must make decisions relating to:

- production continuity
- safety
- supplier coordination
- incident response
- communications
- operational resilience
- recovery strategy

Every decision influences:
- production status
- cyber risk
- safety confidence
- stakeholder trust
- containment effectiveness
- business impact

---

## Learning Themes

The simulation introduces and reinforces concepts including:

- OT vs IT cybersecurity
- remote vendor access risks
- asset registers
- network segmentation
- supplier coordination
- operational resilience
- ransomware response
- safety implications of cyber incidents
- balancing uptime vs security

No specialist cybersecurity knowledge is required.

## Running the Scenario

### Option 1 — Open the Published HTML
If using the exported HTML build:

1. Download the published HTML file
2. Open it in any modern browser
3. Begin the simulation

---

### Option 2 — Open in Twine

1. Install or open Twine:
   https://twinery.org/

2. Import the `.twee` file

3. Ensure the story format is set to:
   `SugarCube 2`

4. Play or edit the scenario

---

## GitHub Pages Hosting

This project can be hosted easily using GitHub Pages.

### Basic Setup

1. Export the story from Twine as HTML
2. Rename the exported file to:
   `index.html`
3. Upload it to the repository root
4. Enable GitHub Pages in repository settings

GitHub will then host the simulation as a browser-accessible webpage.
